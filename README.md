# Проект STM32F107VC для EasyMx PRO v7 в VS Code

Проект настроен для разработки, компиляции, прошивки и отладки микроконтроллера **STM32F107VC** (ARM Cortex-M3) на отладочной плате **EasyMx PRO v7** с использованием программатора **ST-Link** и отладчика **OpenOCD**.

---

## 📁 Структура проекта

* `Core/Src/main.c` — основной код программы (мигание и бегущие огни на светодиодах портов A..E).
* `Core/Inc/main.h` — заголовочный файл.
* `Startup/startup_stm32f107vctx.s` — векторная таблица и код начальной инициализации (GCC).
* `STM32F107VCTX_FLASH.ld` — скрипт компоновщика (256 КБ Flash, 64 КБ RAM).
* `STM32F107xx.svd` — описание регистров периферии для просмотра в отладчике VS Code.
* `openocd.cfg` — конфигурация OpenOCD для работы через ST-Link на частоте 1 МГц по SWD.
* `build.py` — кроссплатформенный скрипт сборки и прошивки.
* `.vscode/`
  * `tasks.json` — задачи VS Code: **Build**, **Flash**, **Clean**.
  * `launch.json` — конфигурация отладки по **F5** (Cortex-Debug + OpenOCD).
  * `c_cpp_properties.json` — настройка путей и IntelliSense для C/C++.
  * `settings.json` — пути к компилятору и OpenOCD.

## ⚡ Как работать в VS Code

### 1. Сборка (Build)
* Нажмите горячие клавиши **`Ctrl + Shift + B`** (или меню *Terminal -> Run Build Task...*).
* Проект скомпилируется в папку `build/`:
  * `firmware.elf` — исполняемый файл для отладчика.
  * `firmware.bin` / `firmware.hex` — бинарные файлы прошивки.

### 2. Прошивка в плату (Flash)
* Меню **Terminal** $\rightarrow$ **Run Task...** $\rightarrow$ выберите **Flash**.
* Либо в терминале выполните:
  ```powershell
  python build.py flash
  ```
* Прошивка автоматически зальется в чип, верифицируется и запустится.

### 3. Отладка по F5 (Debug)
* Нажмите клавишу **`F5`** (или перейдите во вкладку *Run and Debug* и нажмите зеленую стрелку **Debug STM32F107 (OpenOCD)**).
* VS Code автоматически соберет проект, запустит OpenOCD, прошьет контроллер и остановится на первой строке `main()`.
* Доступны:
  * Пошаговое выполнение: **F10** (шаг через), **F11** (шаг внутрь).
  * Точки останова (Breakpoints) кликом мыши слева от номера строки.
  * Переменные в реальном времени: переменные `loop_counter` и `banner` в панели *Variables / Watch*.
  * Регистры периферии: панель *Cortex Peripherals* (GPIOA..GPIOE, RCC и др.).

## 💡 Настройка платы EasyMx PRO v7

На плате EasyMx PRO v7 светодиоды подключаются через DIP-переключатели:
1. Найдите блок переключателей **DIP switch** для светодиодов (например, **SW3** или переключатели с надписью **PORT LEDs** рядом с PORTD или PORTC).
2. Переведите переключатели нужного порта в положение **ON**.
3. На плате включится динамическая анимация: бегущий огонь (пины 0-7) туда и обратно, затем тройное мигание всеми светодиодами.
